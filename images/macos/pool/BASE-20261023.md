## How it was made

A maintenance guest was started from an overlay on the 2026-09-24 base
exactly as the pool starts a runner guest (the appliance image's own
start command behind `/usr/local/bin/nomercy-appliance-start`, the same
mounts, `-p 127.0.0.1:51999:10022`, 8 vCPU / 8 GiB), reached over SSH with
the guest credential the agent holds, given the GitHub template tree from
the verified `uniform-templates.tgz` (owner and mode as the Forgejo one),
shut down with `/sbin/shutdown -h now`, and flattened with
`qemu-img convert -O qcow2` once QEMU had exited. Nothing else in the guest
was touched: no listener was enabled, no registration exists in the base.

`appliance_pool.base_disk` in the appliance host's `agent.json` names this
file; `Install-ApplianceHost.ps1 -PoolBaseDisk` is the setting to pass on a
reinstall.
